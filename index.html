💡 Why Track 33 Landmarks Instead of Classifying Pixels?

Standard image classification would require classifying millions of camera pixels every frame, which would be slow and prone to background clutter. By extracting 33 geometric keypoints first, our movement classification algorithms run on simple vector mathematics in less than 0.1 milliseconds, enabling blazing-fast 60 FPS gameplay on any laptop!

CAMERA SETUP ADVICE:

  • “Make sure your full body is visible to the camera.”
  • Stand 1.8m to 2.5m away with clear lighting.
  • Return to neutral center position between lane movements.

TECHNOLOGY BEHIND THE GAME

CORE AI

MediaPipe Pose

Google's state-of-the-art ML solution for high-fidelity body pose tracking, inferring 33 3D landmarks and background mask from single RGB frames.

GRAPHICS

Three.js & WebGL

Hardware-accelerated 3D graphics rendering the futuristic neon city, dynamic lighting, procedural runner animations, and particle trails.

VISION INPUT

Webcam MediaDevices API

Low-latency browser media capture providing continuous video streaming at native display refresh rates.

ALGORITHMS

Real-Time Pose Tracking & Kinematics

Scale-invariant normalization, Exponential Moving Average (EMA) smoothing filters, and hysteresis state machines preventing accidental inputs.

AUDIO

Web Audio API Synthesizer

Procedural cyber synth sound effects, dynamic retro beats, laser swooshes, and audio feedback generated on-the-fly with zero network latency.

CORE STACK

Modern Vanilla JavaScript (ESNext)

Clean, modular, object-oriented design optimized with requestAnimationFrame for rock-solid 60 FPS performance on standard laptops.

🔬 Science Expo Transparency Note

This project uses Google's pre-trained MediaPipe Pose neural network model compiled to WebAssembly (WASM). No deep-learning model is being trained in real time on this machine; instead, we execute real-time edge inference and perform custom spatial-kinematic analysis to map human landmarks into game physics!
